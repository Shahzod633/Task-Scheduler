# Установка TaskFlow

TaskFlow — локальный канбан-планировщик для Windows. Это настольное приложение
на [Tauri v2](https://v2.tauri.app/): интерфейс на HTML/CSS/JS, бэкенд на Rust,
окно рисует системный WebView2. Все данные хранятся на вашем компьютере, в
зашифрованной базе SQLite (SQLCipher).

Готовых установщиков в репозитории нет — приложение собирается из исходников.
Ниже весь путь от чистой Windows до работающего приложения.

> Поддерживается только **Windows 10/11 x64**: ключ шифрования базы хранится в
> Диспетчере учётных данных Windows, а почта отправляется через системный TLS.
> На macOS и Linux приложение не соберётся в рабочем виде.

---

## 1. Что нужно установить

| Инструмент | Зачем | Обязательно |
|---|---|---|
| [Git](https://git-scm.com/download/win) | скачать репозиторий | да |
| [Node.js](https://nodejs.org/) LTS (18 или новее) | Tauri CLI и запуск сборки | да |
| [Rust](https://rustup.rs/) через `rustup`, тулчейн MSVC, версия ≥ 1.77.2 | бэкенд приложения | да |
| [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) с набором **«Разработка классических приложений на C++»** | компилятор и линкер MSVC, Windows SDK | да |
| [Strawberry Perl](https://strawberryperl.com/) | сборка OpenSSL для шифрования базы | да |
| WebView2 | движок окна | уже есть в Windows 11 |
| [Ollama](https://ollama.com/download) | ИИ-ассистент | нет, только для ассистента |

Большую часть можно поставить через `winget` (PowerShell):

```powershell
winget install Git.Git
winget install OpenJS.NodeJS.LTS
winget install Rustlang.Rustup
winget install StrawberryPerl.StrawberryPerl
```

Visual Studio Build Tools удобнее ставить через обычный установщик: в нём
отметьте набор **«Разработка классических приложений на C++»** (Desktop
development with C++). Подробно про требования Tauri:
<https://v2.tauri.app/start/prerequisites/>.

После установки **откройте новое окно PowerShell** (чтобы подхватился
обновлённый `PATH`) и проверьте:

```powershell
git --version
node --version
rustc --version
(Get-Command perl).Source   # должно быть C:\Strawberry\perl\bin\perl.exe
```

### Почему именно Strawberry Perl

База шифруется SQLCipher, а он работает поверх OpenSSL. OpenSSL собирается из
исходников прямо в приложение — так сборка не зависит от того, что установлено
в системе. Его конфигуратору нужен полноценный Perl. Perl из комплекта Git for
Windows **не подходит**: в нём нет модулей `Locale::Maketext`, и сборка падает в
самом начале. NASM, который тоже нужен OpenSSL, входит в Strawberry Perl —
отдельно его ставить не надо.

## 2. Скачать репозиторий

```powershell
git clone https://github.com/Shahzod633/Task-Scheduler.git
cd Task-Scheduler
npm install
```

`npm install` ставит Tauri CLI и SortableJS (перетаскивание карточек).

---

## 3. Собирать — только из PowerShell (или cmd)

**Не запускайте сборку из Git Bash.** Там путь к библиотекам Strawberry Perl не
складывается, и perl падает с ошибкой `0xc0000135` (не найдены DLL).

Если `(Get-Command perl).Source` показывает не Strawberry, поставьте его первым
в `PATH` для текущего окна:

```powershell
$env:PATH = "C:\Strawberry\c\bin;C:\Strawberry\perl\site\bin;C:\Strawberry\perl\bin;$env:PATH"
```

---

## 4. Запуск в режиме разработки

```powershell
npm run dev
```

Откроется окно TaskFlow — отладочная сборка приложения. Фронтенд берётся прямо
из папки `src/` (HTML/CSS/JS, без сборщика), бэкенд — из `src-tauri/src/`
(Rust); при изменении Rust-кода `npm run dev` пересобирает и перезапускает
приложение.

> **Первая сборка долгая.** OpenSSL компилируется из исходников — у автора это
> заняло около 30 минут. Результат кешируется в `src-tauri\target`, и следующие
> запуски занимают секунды–минуты. Предупреждения `LNK4099` про
> `ossl_static.pdb` безвредны: это отладочные символы OpenSSL.

---

## 5. Сборка установщика

```powershell
npm run build
```

Готовые установщики появятся в `src-tauri\target\release\bundle\`:

- `msi\` — установщик MSI;
- `nsis\` — установщик `…-setup.exe`.

При первой сборке Tauri сам скачивает WiX и NSIS, поэтому нужен интернет.

Установщик не подписан цифровой подписью, поэтому Windows SmartScreen может
показать «Система Windows защитила ваш компьютер». Нажмите **«Подробнее» →
«Выполнить в любом случае»**.

---

## 6. ИИ-ассистент (необязательно)

Ассистент общается с локальной [Ollama](https://ollama.com/) — в интернет
ничего не уходит. Без Ollama приложение работает полностью, не работает только
экран ассистента.

1. Установите Ollama: `winget install Ollama.Ollama` или с
   [ollama.com/download](https://ollama.com/download). После установки она
   слушает `http://localhost:11434`.
2. Скачайте модель **с поддержкой инструментов (tools)** — через них ассистент
   видит доски и задачи. Проверено на qwen2.5 7B:

   ```powershell
   ollama pull qwen2.5:7b
   ```

   Подойдёт и `llama3.1`. Модель полегче отвечает быстрее.
3. В TaskFlow: **Настройки → ИИ-ассистент** → выберите модель → **«Сохранить»**,
   затем **«Проверить подключение»**.

Адрес Ollama принимается только локальный (`localhost`, `127.0.0.1`, `[::1]`).
Первый вопрос после запуска Ollama отвечается дольше — модель загружается в
память. Если ответ не успевает, увеличьте **«Таймаут ответа»** (от 30 до 600 с,
по умолчанию 180).

## 7. Email-напоминания (необязательно)

TaskFlow может прислать письмо о задаче за неделю до срока. По умолчанию
отправка выключена; это единственная функция, которая выходит в сеть.

В **Настройки → Email-напоминания**:

- **SMTP-сервер / порт** — по умолчанию `smtp.gmail.com`, `465`;
- **Логин отправителя** — ваш адрес;
- **Кому присылать** — **замените на свой адрес**: по умолчанию там стоит адрес
  автора проекта;
- **Пароль приложения** — для Gmail нужен именно
  [пароль приложения](https://myaccount.google.com/apppasswords), а не пароль от
  почты. Он хранится в Диспетчере учётных данных Windows, а не в базе.

## 8. Где лежат данные

| Что | Где |
|---|---|
| База | `%APPDATA%\com.taskflow.app\trello_clone.db` |
| Автоматические резервные копии (последние 10) | `%APPDATA%\com.taskflow.app\backups\` |
| Ключ шифрования базы | Диспетчер учётных данных Windows → «Учётные данные Windows» → `TaskFlow` |

Важно:

- **Не удаляйте учётную запись `TaskFlow`** из Диспетчера учётных данных — без
  ключа база не откроется.
- **Файл базы нельзя просто скопировать на другой компьютер**: там другого
  ключа нет, и файл не откроется. Чтобы перенести доску, используйте кнопку
  **«Экспорт»** в шапке доски (сохраняет JSON-файл), а на новом компьютере —
  **«Импортировать доску из файла»** на главном экране рабочего пространства.

## 9. Тесты (для разработчиков)

Тесты Rust — из PowerShell, с тем же Strawberry Perl в `PATH`:

```powershell
cd src-tauri
cargo test --lib
```

Тесты с `#[ignore]` требуют запущенной Ollama или реальной базы и запускаются
отдельно — команда для каждого записана в комментарии над ним.

Проверка работы с датами в разных часовых поясах (тоже из PowerShell: Git Bash
не передаёт `TZ` в Node, и прогон молча идёт в системном поясе):

```powershell
$env:TZ = 'America/New_York'; node scripts/check-dates.mjs
$env:TZ = 'Asia/Tokyo';       node scripts/check-dates.mjs
Remove-Item Env:TZ
```

## 10. Частые проблемы

| Симптом | Причина и решение |
|---|---|
| `Can't locate Locale/Maketext.pm` или похожее при сборке OpenSSL | Используется perl из Git. Поставьте Strawberry Perl первым в `PATH` (шаг 3). |
| Perl падает с `0xc0000135` | Сборка запущена из Git Bash. Запускайте из PowerShell. |
| `linker 'link.exe' not found`, не найден `cl.exe` | Не установлены Build Tools с набором C++ (шаг 1). |
| Сборка будто зависла на `openssl-sys` / `openssl-src` | Это первая компиляция OpenSSL, она идёт десятки минут. Дождитесь. |
| «Ollama не запущена или недоступна по этому адресу» | Запустите Ollama и проверьте адрес в Настройках → ИИ-ассистент. |
| «Модель не ответила вовремя» | Увеличьте таймаут ответа или выберите модель полегче. |
| Ассистент не видит задачи | Выбрана модель без поддержки инструментов. Возьмите qwen2.5 или llama3.1. |
