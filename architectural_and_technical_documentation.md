# Архитектурно-техническая документация: Производительность и стек технологий

## 1. Технологический стек для максимальной скорости
Приложение разработано как высокопроизводительное нативное десктопное решение для Windows 11, объединяющее легковесный фронтенд и системный бэкенд:
- **Бэкенд:** Tauri v2 + Rust. Использование Rust гарантирует максимальную скорость выполнения операций на уровне железа, эффективное управление памятью и безопасность без мусорщика (Garbage Collector).
- **База данных:** SQLite. Локальное хранение всех данных (пространств, досок, колонок, карточек, настроек автоматизации) в локальном файле `trello_clone.db`, что полностью исключает любые сетевые задержки.
- **Фронтенд:** HTML5 / CSS3 / JavaScript с использованием современных сеток CSS Grid / Flexbox и библиотеки `Sortable.js` для мгновенного и плавного интерактивного взаимодействия (Drag-and-Drop).

---

## 2. Ключевые показатели производительности
- **Потребление оперативной памяти:** В пределах **20–30 МБ**. В отличие от приложений на базе Electron (которые тянут за собой гигантский инстанс Chromium и Node.js), Tauri использует нативный системный компонент Windows 11 — **WebView2**.
- **Мгновенный холодный запуск (Cold Start):** Приложение открывается за доли секунды благодаря отсутствию тяжелых веб-фреймворков и быстрой инициализации бэкенда на Rust.
- **Полная автономность:** Программа работает полностью локально без подключения к интернету, внешних зависимостей, подписок и искусственных ограничений функционала.

---

## 3. Архитектурные механизмы быстрой работы
- **Локальный обмен через Tauri IPC:** Взаимодействие между интерфейсом (WebView) и бэкендом (Rust) происходит напрямую через нативные IPC-мосты Tauri, обеспечивая моментальную запись и чтение данных из базы SQLite.
- **Оптимизированный рендеринг:** Отказ от избыточных виртуальных DOM-деревьев в пользу чистого легковесного JS и нативных возможностей браузерного движка Windows гарантирует плавность анимаций при работе с сотнями карточек и колонок.
