# Полная UI/UX и функциональная спецификация: Локальный аналог Trello (Windows 11)

## 1. Общая визуальная концепция и дизайн-система (UI/UX)
- **Цветовая палитра:** Глубокая темная тема в стиле современного интерфейса Windows 11. Основной фон приложения — глубокий угольно-серый (`#181a1f` / `#1d1f24`), боковая панель — чуть темнее для создания визуальной иерархии. Карточки досок и элементов имеют полупрозрачные темные подложки с легким скруглением (`border-radius: 8px` / `12px`).
- **Акценты и брендинг:** Используется фирменный синий цвет Trello (`#0079bf` / `#026aa7`) для ключевых кнопок (например, кнопка **«Создать»** в шапке) и градиентные переливы (фиолетово-розовые градиенты для превью досок).
- **Типографика:** Чистый системный шрифт без засечек, высокая контрастность белого текста на темном фоне для комфортного чтения.

## 2. Детальный разбор экранов и визуальных компонентов

### Экран А: Главный навигационный хаб (Workspace & Dashboard View)
- **Верхняя глобальная панель (Header):**
  - **Логотип:** Иконка Trello и текстовое название в левом углу.
  - **Поисковая строка:** Широкое поле по центру с иконкой лупы и плейсхолдером *«Поиск»*, позволяющее мгновенно фильтровать проекты по всей базе.
  - **Кнопка создания («+ Создать»):** Выделена ярким синим цветом с подсветкой, служит универсальной точкой входа для генерации новых досок или пространств.
  - **Системные блоки справа:** Индикатор пробного периода (*«Осталось дней: 14»* в виде розово-фиолетовой плашки), иконка уведомлений (колокольчик), справка и аватар профиля пользователя (`SS`).
- **Левая боковая панель (Sidebar):**
  - Разделы навигации: *«Доски»*, *«Шаблоны»*, *«Главная страница»* с соответствующими иконками.
  - Блок **«Рабочие пространства»**: интерактивный список, где отображается текущее пространство (*«Рабочее пространство Trello»*).
- **Центральная рабочая зона:**
  - **Баннер шаблонов (Jira / Trello Templates):** Блок с предложением начать работу с шаблонов (*«Управление проектами»*, *«Scrum»*, *«Отслеживание ошибок»*, *«Процесс веб-дизайна»*). Каждая карточка шаблона оформлена в виде яркого синего блока с иконкой стрелки перехода вправо-вверх. Блок можно закрыть с помощью крестика в правом верхнем углу.
  - **Секция «Мои доски» / Недавно просмотренное:** Визуальная сетка карточек досок. 
    - *Карточка доски:* Имеет красивое градиентное превью (розово-фиолетовый градиент) и текстовую подпись белым цветом *«Моя доска Trello»*.
    - *Карточка «Создать доску»:* Интерактивный прямоугольный блок с темной заливкой и тонкой градиентной рамкой (переливающейся сине-фиолетово-желтым спектром), при наведении на который активируется эффект подсветки.

### Экран Б: Панель управления рабочим пространством (Workspace Management View)
При разворачивании или переходе в настройки конкретного пространства интерфейс дополняется следующими элементами:
- **Расширенное подменю в сайдбаре:** Под «Рабочее пространство Trello» выпадают пункты:
  - *Доски* (активный пункт с синей подсветкой).
  - *Участники* (с кнопкой добавления «+»).
  - *Настройки* (шестеренка).
  - *Оплата* (информация о тарифе).
- **Шапка рабочего пространства на главном экране:**
  - Название *«Рабочее пространство Trello»* сопровождается иконкой редактирования (карандаш).
  - Мета-метки статуса: **Premium** (тип подписки) и **Приватная** (уровень видимости с иконкой замка).
- **Дополнительные опции:** Кнопка *«Посмотреть закрытые доски»* внизу блока для доступа к архиву удаленных проектов.

### Экран В: Активная Kanban-доска (Board Workspace View)
Открывается по клику на любую карточку доски (например, «Моя доска Trello»):
- **Верхняя панель доски:**
  - Слева: Название доски *«Моя доска Trello»* и иконка переключения представлений (`000`).
  - Справа: Инициалы пользователя (`SS`), иконка Power-Ups (пазл), иконка автоматизации (молния), иконка фильтров (воронка), кнопка добавления в избранное (звездочка), индикатор приватности (замок), кнопка **«Поделиться»** (светло-серая плашка) и меню дополнительных опций (`...`).
- **Колонки задач (Kanban Columns):**
  Доска разделена на вертикальные скругленные колонки с темным фоном:
  1. *«Руководство по началу работы с Trello»* (содержит карточки с медиаконтентом):
     - *Карточка 1:* Видео-превью с синей кнопкой Play в центре и подписью *«New to Trello? Start here»* (источник — Loom).
     - *Карточка 2:* Текстово-графический блок с миниатюрами интерфейса и описанием *«Фиксируйте данные из электронной почты, Slack и...»*.
     - Кнопка внизу колонки: `+ Добавить карточку` и иконка быстрого создания.
  2. *«Сегодня»* (пустая колонка, счетчик задач `0`, кнопка `+ Добавить карточку`).
  3. *«На этой неделе»* (счетчик `0`, кнопка добавления).
  4. *«Позже»* (счетчик `0`, кнопка добавления).
  5. Крайний элемент справа: Кнопка-строка `+ Добавьте еще одну колонку` для масштабирования структуры доски.

### Экран Г: Плавающая нижняя панель (Floating Dock)
Располагается в самом низу экрана поверх доски в виде компактного плавающего бара с темным полупрозрачным фоном и эффектом размытия (Blur):
- Кнопка **Inbox** (с иконкой папки).
- Кнопка **Планировщик** (с иконкой календаря).
- Кнопка **Доска** (активный режим, выделен синей нижней полоской-индикатором).
- Кнопка **Выбрать другую доску** (возврат на главный экран управления пространствами).

## 3. Интерактивная логика и сценарии работы (User Flows)
1. **Сценарий запуска и навигации:**
   - При старте приложения пользователь попадает на **Главный навигационный хаб** (Экран А).
   - Клик по карточке «Моя доска Trello» мгновенно переключает представление WebView на **Активную Kanban-доску** (Экран В) с плавающей нижней панелью.
   - Клик по кнопке *«Выбрать другую доску»* на плавающей панели возвращает пользователя обратно в хаб.
2. **Управление колонками и карточками:**
   - Нажатие на `+ Добавьте еще одну колонку` открывает поле ввода названия новой колонки, которая сразу сохраняется в локальную базу данных SQLite через Tauri IPC.
   - Перетаскивание карточек между колонками (*Руководство*, *Сегодня*, *На этой неделе*, *Позже*) осуществляется с помощью плавной библиотеки `Sortable.js`.
3. **Мультипанельный режим (Split-View):**
   - Пользователь может активировать одновременный показ панели **Inbox** (для быстрого сбора идей) и **Календаря** рядом с доской благодаря гибкой сетке CSS Grid, перетаскивая задачи между ними мышкой в реальном времени.

## 4. Техническая реализация (Бэкенд на Rust + SQLite)
- **Хранение данных:** Все созданные пространства, доски, колонки, карточки и настройки автоматизации записываются в локальный файл `trello_clone.db` с использованием **SQLite**.
- **Производительность:** Нативный движок WebView2 в связке с Rust гарантирует мгновенный отклик интерфейса, отсутствие задержек сети и потребление оперативной памяти в пределах **20–30 МБ**.
